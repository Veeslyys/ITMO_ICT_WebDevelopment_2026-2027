Лабораторная работа 1
Тема: Работа с сокетами в Python

Цель работы:
Изучить основы работы с библиотекой socket и реализовать простые клиент-серверные приложения с использованием протоколов UDP и TCP.

Задание 1:
Были реализованы UDP-сервер и UDP-клиент. Клиент отправляет сообщение "Hello, server". Сервер принимает сообщение, выводит его на экран и отправляет клиенту ответ "Hello, client".

Файлы:
task1_udp/udp_server.py
task1_udp/udp_client.py

Задание 2:
Были реализованы TCP-сервер и TCP-клиент для выполнения математической операции. В качестве варианта выбрана теорема Пифагора. Клиент вводит два катета, отправляет их серверу, сервер вычисляет гипотенузу и возвращает результат.

Файлы:
task2_tcp_math/tcp_math_server.py
task2_tcp_math/tcp_math_client.py

Задание 3:
Был реализован простой HTTP-сервер. При подключении клиента сервер загружает файл index.html и отправляет его в виде HTTP-ответа.

Файлы:
task3_http_file/http_server.py
task3_http_file/index.html

Задание 4:
Был реализован многопользовательский чат на TCP. Сервер принимает подключения нескольких клиентов и пересылает сообщения другим пользователям. Для обработки клиентов используется библиотека threading.

Файлы:
task4_chat/chat_server.py
task4_chat/chat_client.py

Задание 5:
Был реализован простой веб-сервер для обработки GET и POST HTTP-запросов. Сервер принимает название дисциплины и оценку, сохраняет данные в список и выводит все оценки на HTML-странице.

Файл:
task5_web_grades/web_grades_server.py

Вывод:
В ходе лабораторной работы были изучены основные принципы работы с сокетами, протоколами UDP и TCP, а также простая обработка HTTP-запросов с помощью библиотеки socket.
